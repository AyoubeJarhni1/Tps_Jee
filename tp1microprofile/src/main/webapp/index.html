🚀 TP1 MicroProfile

API REST avec MicroProfile - Gestion de Produits et Clients

📋 Information: Cette application utilise MicroProfile pour fournir une API REST complète avec Health Checks, Metrics et OpenAPI.

📦 Endpoints Produits

GET /api/products
Récupérer tous les produits
GET /api/products/{id}
Récupérer un produit par ID
GET /api/products/category/{category}
Récupérer les produits par catégorie
POST /api/products
Créer un nouveau produit
PUT /api/products/{id}
Mettre à jour un produit
DELETE /api/products/{id}
Supprimer un produit

👥 Endpoints Clients

GET /api/clients
Récupérer tous les clients
GET /api/clients/{id}
Récupérer un client par ID
POST /api/clients
Créer un nouveau client
PUT /api/clients/{id}
Mettre à jour un client
DELETE /api/clients/{id}
Supprimer un client
